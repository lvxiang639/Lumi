# 灵犀 UI 重塑设计：底部导航 + 发现页 + 我的页

> 日期：2026-06-06 | 状态：设计阶段

## 目标

将灵犀从"单一聊天页面 + 浮动工具面板"重构为"底部三 Tab 导航"应用：

- **对话 Tab**：对话列表 → 聊天页（AI 消息在左，用户在右）
- **发现 Tab**：个人 dashboard + AI 信息流（朋友圈风格）
- **我的 Tab**：个人信息 + 助手工具（原工具面板迁移至此）
- OCR 功能去掉，工具统一改称"助手"

## 一、导航结构

```
app.dart → 登录校验 → MainScreen（底部三 Tab）
                            │
              ┌─────────────┼─────────────┐
              ▼             ▼             ▼
        ConversationList   Discover     Profile
              │                              │
              ▼                              ▼
          ChatScreen                     (助手工具弹窗/页面)
```

## 四、数据流

### 聊天页助手流程

```
对话页 → 点击"助手"按钮
  → 弹出助手菜单（AssistantMenu）
  → 用户选择功能（总结邮件/笔记/摘要）
  → 调用对应的后端 API
  → 显示结果
```

### 发现页 AI 动态流程（未来）

```
后端定时任务/用户打开发现页时
  → AI 根据天气、时间、用户情绪生成内容
  → 返回前端 → 展示在信息流
  → 未来接入 RSS 热点抓取
```

## 五、科幻 icon 分配

```dart
const _convIcons = ['🚀', '🌌', '🛸', '🤖', '🌟', '💫', '🔭', '🪐', '👾', '⚡', '🌀', '🎯'];
String _iconFor(String id) => _convIcons[id.hashCode.abs() % _convIcons.length];
```

根据对话 ID 的 hashCode 确定 icon，同一个对话始终显示同一个。

## 六、实现顺序

1. **MainScreen 底部导航 + 路由变更** → app.dart, main_screen.dart
