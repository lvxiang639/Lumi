# AI Agent

## 功能
用户通过对话触发多步骤任务，Agent 自动规划并调用技能完成。

## 触发条件
用户消息包含以下关键词之一:
- "并"、"然后"、"顺便"、"同时"、"再帮我"、"也帮我"、"还有"

## 流程
```
用户: "帮我查天气然后记个账"
    │
    ▼
意图分类 → agent (关键词匹配)
    │
    ▼
DeepSeek 拆分任务: [查天气, 记账]
    │
    ▼
依次执行: weather_skill → expense_skill
    │
    ▼
结果合并: "今天北京晴 25°C\n已记: 餐饮 50元"
```

## 已注册技能
| 技能 | 触发词 | 说明 |
|------|--------|------|
| weather | "天气" | 查询天气 |
| calendar | "日程"、"提醒" | 日历管理 |
| expense | "记账"、"花了" | 记账 |
| search | "搜索"、"查一下" | 搜索信息 |
| convert | "转换"、"转格式" | 文件转换 |
| briefing | "简报"、"早上好" | 每日简报 |
| email | "发邮件"、"邮件" | 邮件发送 |

## Agent 执行逻辑
```
1. DeepSeek 分析用户输入 → 拆分为子任务列表
2. 逐个执行子任务 → 调用对应 skill
3. 合并结果 → 返回用户
```

## 技能调度
```
对话消息
  ├─ 意图分类(DeepSeek)
  │   └─ agent / weather / calendar / expense / search / ...
  ├─ Agent: 多步骤规划 → 逐个调 skill
  ├─ Skill: 直接执行 → 返回结果
  └─ Chat: 普通对话 → LLM 回复
```
